# Sample Questions

Run these after building the index in the Colab notebook.

```text
How do I make a Mojito?
What ingredients and glass are used for a Negroni?
Which cocktails use rum and lime?
How do I make a refreshing cocktail with ginger?
What is the penalty for late submission?
```

The final question is deliberately outside the cocktail dataset. The assistant should return the insufficient-evidence message instead of inventing an answer.
